# MaTCo
(Materials for the Mathematics Tournament Committee 2026 / 2027)

This repository was created serve as an archive for the materials being covered, problem sets which get solved, and anything else that might be of interest which was covered during the MaTCo sessions. The idea is to have a to-go place for people to access the materials, and check on anything they might have missed. If you see something missing, or want to see more info on certain topics please let us know and we will take care of it!

Sincerely, the MaTCo Board :)
